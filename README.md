# 📖 Project Overview

This project is a modern and responsive personal portfolio website developed using HTML5, CSS3, and JavaScript.

The portfolio showcases my skills, projects, education, and contact information in a clean and professional design.

The website is fully responsive and works smoothly on desktop, tablet, and mobile devices.

---

# ✨ Features

- Fully responsive design for desktop, tablet, and mobile devices  
- Smooth scrolling navigation bar  
- Attractive hero section with profile details  
- Skills section with modern cards  
- Projects section with GitHub and live demo links  
- Contact section with social media links  
- Clean and professional UI design  
- Interactive hover effects and animations  
- Hosted online using GitHub Pages  
- Easy to customize and update
